# Visense

把一瞬灵感，留给下一次创作。

Visense 是面向摄影、插画、视觉设计与内容创作者的移动端视觉灵感采集助手。本仓库为可直接运行的静态交互演示，无需安装依赖或构建。

## 在线体验

- [Cloudflare Pages](https://visense.pages.dev/)
- [GitHub Pages 备用地址](https://jiangyuxuan765-sudo.github.io/visense/)

Cloudflare Pages 连接本仓库的 `main` 分支；后续提交自动触发部署。

## 使用

通过网站访问，或下载后在现代浏览器中打开 `index.html`。支持灵感采集、分类搜索、项目整理、浅色与深色模式，以及资料备份和 PDF 参考页导出。

图片、笔记和个人设置保存在当前浏览器，不上传至服务器。AI 观察为明确标注的演示内容，未连接远程 AI 服务。
